# RAG-based-Study-Assistant
An end-to-end RAG pipeline that lets students query their own PDF notes using natural language. Features hybrid semantic + BM25 retrieval, CrossEncoder reranking, and Groq LLaMA 3.3 inference — achieving 95%+ faithfulness on RAGAS evaluation. Built with LangChain, ChromaDB &amp; Streamlit.Project based on student's database.
