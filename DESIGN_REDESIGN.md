# Chat-first UI redesign

The frontend has been reworked toward a quieter, conversation-first study experience:

- Removed the right-hand study tips panel and decorative sidebar promotion.
- Reduced the sidebar to the main navigation and a New lecture action.
- Replaced dashboard metrics and repeated feature cards with a centered study prompt, one upload/link composer, and a short recent lecture list.
- Simplified the empty chat state, message styling, and composer.
- Reduced sign-in and registration copy and softened control corners without using pill-shaped buttons.
- Used neutral light/dark surfaces with a restrained teal accent.
- Kept the existing login, registration, student/admin/farmer roles, and server-side access checks in place.

The redesign does not make the service production-ready by itself. Follow the authentication and data-access guide and launch checklist before publishing the site.
